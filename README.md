# Intro to React App - Dynamic Todo List
---

This project is part of the **Code the Dream Intro to React course**.  
It covers a simple to-do list web app that helps users create, organize, and manage tasks.

**Installation**
Clone the repository, install dependencies with npm by running  ```npm install ``` and set up the project locally.

**Run the Development Server**
Start the project using ```npm start ``` or ```npm run dev``` to view it in your browser.
